### 포함 변경

- 기존 로컬 테스트 표시 `0.1.0`을 새 기준 `0.0.1`로 정리. 앱 식별자/저장 위치와 저장 형식은 유지.
- Nero 23-B r7 A 아이콘, 한국어 재생/메뉴, 테마와 설정 분류 반영.
- 녹음 권한 완료 대기, 시작 순서, 비종료 오디오 경고 보존, 자동 음성 변환/취소, 부유창 표시 정책 반영.
- 자동 저장과 선택 전환 보존, 회의 날짜/실제 녹음 시각 분리, 기본 이름 중복 회피, 목록 시각 표시.
- 온디바이스 회의록, 선택 모델 다운로드와 진행률, 음성 기록/회의록 복사와 TXT/Markdown 내보내기.
- 버전 미러 검사, 소스 커밋/dirty 상태를 포함한 앱 내부 빌드 정보, 서명/공증 ZIP과 DMG 생성 경로 추가.
- macOS/Windows 기능과 검증 범위는 별개다. 화자 처리, Calendar 연결과 Windows 실제 실행 검증은 완료 기능에 포함하지 않는다.
