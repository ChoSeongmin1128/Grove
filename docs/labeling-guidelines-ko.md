# 한국어 원음 검수 지침

상태: **Planned / 첫 지침 초안, 미구현** · guideline version: `ko-verbatim-v0.1` · 2026-09-03

AI-assisted 지침입니다. 아래 규칙을 구현 전 합성 fixture로 고정하고 실제 검수에서 모호한 사례를 기록하십시오. 프로젝트 기본값에 업무명·개인명·개인 회의 예시를 넣지 않습니다.

## 기본 원칙

1차 결과는 **원음의 실제 발화 교정**입니다. 읽기 좋은 회의록 재작성·말뜻 요약·문법 개선 기능을 추가하지 않습니다. 모델 결과, 사전, 문맥은 듣기 위한 보조 자료일 뿐 원음을 대신하는 정답이 아닙니다.

| 상황 | 기록 규칙 |
|---|---|
| 머뭇거림·추임새 | 들린 언어적 `어`, `음`, `네` 등을 임의 삭제하지 않음 |
| 반복·말 바꿈·비문 | 들린 반복/자기수정을 유지. 문법상 자연스럽게 합치거나 완성하지 않음 |
| 끊긴 단어·불명확 음절 | 확실한 부분만 기록하고 나머지의 불명확 범위를 구조화. 문맥으로 빈칸을 단정하지 않음 |
| 띄어쓰기·문장부호 | 일반 한국어 표기로 읽기 가능하게 하되 말의 단어/순서를 바꾸지 않음. 문장부호는 발화 내용과 구별 |
| 숫자·단위 | 실제 읽은 형태를 우선 기록. 예: 합성 발화 `열두 개`, `일 점 이`. 표시용 숫자 변환은 별도 파생 자료이며 원본 교정문을 덮어쓰지 않음 |
| 영문·약어·기술 용어 | 식별이 확실한 관용 철자는 기록 가능. 예: 명확한 철자 발화 `에이피아이`를 `API`로 기록하는 규칙은 지침/정규화 버전에 고정. 애매한 경우 들린 형태와 uncertain을 남기며 사전으로 억지 확정하지 않음 |
| 이름·동음어 | 소리와 사용 문맥을 함께 확인하되 확인되지 않은 실명을 만들어 넣지 않음. 동일 사람을 구분할 수 있으면 익명 화자 ID만으로 유효 |
| 웃음·기침·환경음 | speech 텍스트에 일반 단어로 섞지 않고 nonSpeechEvent로 분리. 말하며 웃는 경우 들리는 말과 사건을 각각 보존 |
| 둘 이상 동시 발화 | 같은 시간대의 복수 화자를 유지. 한 사람으로 강제 합치거나 시간을 밀어 겹침을 제거하지 않음 |

숫자/약어 표기는 평가 결과를 본 뒤 특정 엔진에 유리하게 바꾸지 않습니다. 표시 교정문과 CER/WER 정규화 함수는 별개 버전으로 고정합니다. 이 지침의 표기와 기존 개인 회귀 기준이 다르면 그 차이를 기록하고 옛 점수를 조용히 덮어쓰지 않습니다.

## 텍스트·화자·시각은 각각 확인

- 텍스트 확인: 선택 음성과 교정문이 실제 발화 수준에서 일치하는지 판단합니다. 아무것도 고치지 않아도 명시적으로 확인할 수 있습니다.
- 화자 확인: 회의 내 동일 인물 구분입니다. 실제 이름을 몰라도 익명 화자 ID로 완료할 수 있습니다. 폴더 저장 이름을 골랐다는 이유만으로 자동 완료하지 않습니다.
- 시각 확인: 들리는 시작/끝을 정밀 재생과 문맥 재생으로 비교합니다. 타임라인 표시 반올림을 정답으로 복사하지 않습니다.
- 불명확: `textUnintelligible`, `speakerAmbiguous`, `boundaryUncertain`, `overlapUnresolved`처럼 축/범위별 사유를 남깁니다. 빈 문자열·없는 ID를 정답처럼 내보내지 않습니다.

텍스트를 못 알아들어도 누가 언제 말했는지를 확인할 수 있고 그 반대도 가능합니다. 확인된 축만 저장하며, 한 축의 완료가 나머지 축을 승인하지 않습니다.

## 독립 활동과 완전성

전사 구간은 문장/발화 단위이므로 내부 침묵을 포함할 수 있습니다. 독립 화자 활동 정답은 **실제 말소리가 있는 구간**을 따로 검수합니다. 전사 경계 복사로 활동 검수를 끝내지 않습니다.

- 발화 목록 전체를 확인한 뒤에도 모델이 놓친 발화가 없는지는 별도 범위 검수가 필요합니다.
- `전사 누락까지 확인`과 `화자 활동/침묵까지 확인`은 서로 다른 범위 승인입니다.
- 범위를 끝까지 듣고 숨겨진 발화·짧은 응답·겹침·침묵을 확인한 후 명시적으로 표시합니다. 재생 완료나 항목 수로 자동 승인하지 않습니다.
- 오검출 전사를 삭제해도 그 시간대를 무음으로 승인한 것이 아닙니다. 다른 사람의 빠진 말 또는 말이 아닌 소리가 있을 수 있습니다.
- 확인된 침묵은 화자 활동 RTTM 행이 없지만 평가 UEM에는 포함할 수 있습니다. 미검수 공백을 침묵으로 추정하지 않습니다.
- 불명확 범위의 시작/끝을 아직 알 수 없으면 평가 제외 사유와 검수 필요 상태를 남깁니다. 근거 없는 끝 시각으로 interval을 만들지 않습니다.

## 편집 후 확인 순서

| 편집 | 다시 확인할 것 |
|---|---|
| 단어 수정 | 수정된 실제 발화 텍스트. 발화 구성·구간·불명확/제외 상태까지 바뀐 경우에만 관련 완전성 범위도 재검수 |
| 화자 배정/실체 병합 | 변경된 모든 발화·활동의 실제 사람. 필터에 숨겨진 대상도 포함 |
| 경계 이동 | old∪new 범위와 새로 생기거나 사라진 겹침, 잘린/추가된 말 |
| 추가/분할/병합 | 새 항목별 텍스트·화자·경계, 원래 출처와 누락 여부 |
| 삭제 | 삭제 전 시간대에 빠진 다른 말이 없는지. 무음 승인은 별도 |
| 표시 이름/제목 수정 | 표기만 바뀌었다면 음성/전사 검수 전체를 다시 요구하지 않음 |

입력과 검수를 한 번에 완료하는 명령을 만들더라도 사용자에게 무엇을 확인하는지 명시해야 합니다. 일반 텍스트 저장만으로 verified를 기록하지 않습니다.

## 검수 완료와 사용 승인

첫 베타의 JSON 백업에는 미검수·불명확·legacy 수정도 보존할 수 있습니다. 그것이 학습 정답은 아닙니다. ASR, diarization, speaker-attributed ASR 각각의 검수/범위 조건은 [내보내기 계약](dataset-export.md)이 결정합니다.

검수 완료는 품질 판정이고 학습 사용·외부 제공 동의가 아닙니다. 학습 승인은 기본 미승인으로 두며 목적별 명시 승인이 있어야 합니다. 이름을 가린다고 목소리가 익명화되는 것도 아닙니다.

## 지침 변경과 완료 기준

- 단어 표기·음성 종류·경계 판단 규칙을 바꾸면 guideline version을 갱신합니다. 단순 문서 오탈자는 의미 변경 여부를 기록합니다.
- 기존 증거는 당시 지침에 묶어 보존합니다. 새 지침의 정답으로 내보내려면 변경 영향을 검토하고 해당 축/범위를 재검수합니다. 일괄 verified 복사는 금지합니다.
- 합성 예제로 숫자/약어/반복/짧은 응답/불명확/겹침/침묵의 기대 라벨과 제외 사유를 고정합니다.
- 반복 사용한 3분 파일은 개발·회귀 검수용입니다. 품질 개선 판단에는 다른 회의의 독립 holdout과 지침 일관성 확인이 추가로 필요합니다.
